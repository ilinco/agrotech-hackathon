# Агромониторинг

Адаптивная карта полей на React, TypeScript, Vite, Tailwind CSS и React Leaflet.

На главной странице доступны выбор тестового поля на карте или в списке, просмотр координат, скрытие контура, изменение масштаба и возврат к полю. На телефоне информация о поле расположена под картой, на широком экране — слева. Масштаб карты можно менять колёсиком мыши, кнопками карты или жестом двумя пальцами.

Контур в `src/pages/map/demoField.ts` — изолированный синтетический пример, а не границы реального поля. Снимки и сервис анализа пока не подключены; вкладка снимков показывает пустое состояние.

## Запуск

```bash
pnpm install
cp .env.example .env
pnpm dev
```

При подключении бэкенда задайте `VITE_API_URL` в `.env`. Переменные с префиксом `VITE_` доступны в браузере — не храните в них секреты. Стартовая страница не отправляет API-запросы.

Карта загружает тайлы OpenStreetMap по сети. Поставщик настраивается через `VITE_MAP_TILE_URL` и `VITE_MAP_ATTRIBUTION`; при его замене укажите требуемую атрибуцию. Перед production-развёртыванием выберите поставщика с подходящими условиями и лимитами. При ошибке загрузки карты доступна повторная попытка.

## Команды

- `pnpm dev` — сервер разработки.
- `pnpm build` — проверка TypeScript и production-сборка.
- `pnpm lint` — проверка ESLint.
- `pnpm preview` — локальный просмотр сборки.

## Структура

```text
public/                 Статические файлы
src/
  api/                  Общий Axios-клиент
    services/           Сервисы будущего API
  assets/
    styles/             Глобальные стили и Tailwind
  components/
    layout/             Каркас страницы и контейнер
    providers/          Корневой провайдер приложения
    ui/                 Общие UI-компоненты
  config/               Константы и настройки
  context/              React-контексты
  hooks/                Пользовательские хуки
  pages/                Страницы
  routing/              Маршруты
  types/                Общие типы
  App.tsx               Основной layout
  main.tsx              Точка входа
```

Алиас `@/` указывает на `src/`. Главный маршрут `/` открывает карту полей. Компонент карты и тестовый контур находятся в `src/pages/map/`. В пустых каталогах находятся `.gitkeep`, чтобы сохранить структуру в Git.

Зависимости и lock-файл сохранены. `.gitignore` исключает локальное окружение, зависимости, сборку, кэши и отчёты проверок; `.env.example` и `pnpm-lock.yaml` предназначены для коммита.
